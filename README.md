# Projeto-ramsonware
Este é um projeto pessoal onde desenvolvi um ramsonware que pode ser usado de teste para aplicativos que usam monitoramento em tempo real 

# Funcionamento:
## Este ransomware foi desenvolvido por mim, onde fiz um ransomware que criptografa arquivos com AES-256 na pasta em que ele está (para ter menos danos) o arquivo que criptografa é o app.py. Basta rodar python app.py no terminal. 

# Decrypt.py:
## Esse arquivo ele descriptografa o arquivo acima, casa haja a execção do primeiro de forma inesperada. 

### Salve o arquivo decrypt.py em uma outra pasta para não correr o risco de ser criptografados junto do ambiente de teste.

# Considerações:
## Lembrando que é um ramsonware fraco porém, ainda pode causar perdas. Não teste em ambiente empresarial. O desnvolvedor não se compromete com os danos causados por esse ransomware, é um elemento feito para estudo e testes em ambientes controlados.
